# Dataset

This project uses the Brazilian E-Commerce Pubic dataset by Olist.

## Source

The dataset is available on Kaggle.

[Download Dataset from Kaggle](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)

## Files

The dataset contains information about:

- Customers
- Orders
- Order items
- Products
- Payments
- Reviews
- Sellers
- Geolocation

> Note: The raw CSV files are not included in this Github repository.
> because of their size. Please download the dataset directly from kaggle.
